# Task Planner

Учебный проект по дисциплине **«Разработка веб-приложений с использованием технологий ASP.NET и AJAX»**.

Тема проекта: **планировщик задач с версионированием API**.

## Описание

В проекте показано развитие структуры задачи между двумя версиями API.

### API v1

Версия `v1` содержит базовые поля задачи:

- `id` — идентификатор задачи;
- `title` — название задачи;
- `date` — дата выполнения;
- `completed` — статус выполнения.

Пример структуры:

```text
TaskV1
├── id
├── title
├── date
└── completed
```

### API v2

Версия `v2` сохраняет поля из `v1` и дополнительно читает два новых поля:

- `priority` — приоритет задачи;
- `category` — категория задачи.

Пример структуры:

```text
TaskV2
├── id
├── title
├── date
├── completed
├── priority
└── category
```

## Расписание версий

| Версия | Поля |
|---|---|
| v1 | id, title, date, completed |
| v2 | id, title, date, completed, priority, category |

## Архитектура

```text
Task Planner
│
├── API v1
│   └── TaskV1
│
└── API v2
    └── TaskV2
```

В учебном примере логика показана на C++. Отдельные структуры `TaskV1` и `TaskV2` демонстрируют, как может изменяться модель данных между версиями API.

## Файлы проекта

- `main.cpp` — основной код программы;
- `README.md` — описание проекта и версий API.

## Компиляция

Если установлен `g++`:

```bash
g++ main.cpp -o taskplanner
```

## Запуск

Windows:

```bash
taskplanner.exe
```

Linux/macOS:

```bash
./taskplanner
```

## Пример результата

```text
API v1
ID: 1
Название: Сделать лабораторную
Дата: 30.09.2026
Выполнено: Нет

API v2
ID: 2
Название: Подготовить проект
Дата: 05.10.2026
Выполнено: Нет
Приоритет: 1
Категория: Учёба
```

## Вывод

Версионирование позволяет добавлять новые возможности без изменения старой версии. В `v2` к задаче добавлены поля `priority` и `category`, а структура `v1` остаётся без изменений.
