# Антипаттерны из конспекта

```http
GET /deleteUser?id=1
```

Удаление через `GET`.

```http
POST /getUsers
```

Получение данных через `POST`, когда подходит `GET`.

```text
200 OK c {"error":"..."}
```

Ошибка передаётся в теле при HTTP 200 вместо корректного HTTP-статуса.

```text
401 вместо 403
```

Неверное использование `401 Unauthorized` вместо `403 Forbidden`.
