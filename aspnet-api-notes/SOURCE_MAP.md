# Карта исходного конспекта

- Страницы 1–2: ETag, If-None-Match, If-Match, Idempotency-Key, REST-методы, антипаттерны.
- Страницы 3–4: Model Binding, `[FromRoute]`, `[FromQuery]`, `[FromBody]`, `[FromHeader]`,
  `[FromServices]`, `[BindNever]`, custom `IModelBinder`, `ModelState`.
- Страница 5: DTO, mapper, DataAnnotations.
- Страницы 6–7: собственный `ValidationAttribute`, `IValidatableObject`,
  вложенные объекты, FluentValidation.
- Страницы 8–10: `ProblemDetails`, `ValidationProblemDetails`,
  `CustomProblemDetailsFactory`.
- Страницы 10–11: `IExceptionHandler`, `GlobalExceptionHandler`,
  `AddExceptionHandler`, `UseExceptionHandler`.
